Free hook: public repo `daggate-lite` (5 rules: DG101, DG102, DG203, DG301, DG201) + full checklist PDF. README links to paid kit. This is the top of funnel.

## Day 1 (Mon) — Ship
- Publish Gumroad listing ($39) + 5 images.
- Publish daggate-lite repo on GitHub (MIT for the lite subset only, clearly separated from paid code).
- Personal LinkedIn post: "Every Airflow outage I've debugged in 15 years of pipeline work traces to the same 16 mistakes. I turned them into a CI gate." + terminal GIF + repo link.

## Day 2 (Tue) — Technical article
- dev.to + personal blog: "Your Airflow DAGs are not production-ready (a checklist and a linter)". 1200 words, genuinely useful standalone, lite repo linked, kit linked once at end. Cross-post to Medium.

## Day 3 (Wed) — Reddit r/dataengineering
- Text post sharing the FREE lite tool + checklist, transparent "I sell a fuller version" disclosure per subreddit rules. Answer every comment. Do not spam.

## Day 4 (Thu) — Hacker News Show HN
- "Show HN: daggate-lite – dependency-free static checks for Airflow DAGs" pointing at the GitHub repo (never the sales page). Be present in comments all day.

## Day 5 (Fri) — Airflow community
- Apache Airflow Slack #random / #user-troubleshooting where tool-sharing is allowed (read rules first); Airflow subreddit. Share lite repo only.

## Day 6 (Sat) — Astronomer/data newsletters + demo video
- Submit lite repo to Data Engineering Weekly, Airflow newsletter, awesome-apache-airflow list (PR).
- Record 45s demo video; add to Gumroad + LinkedIn.

## Day 7 (Sun) — Measure & first scorecard
- Fill analytics/scorecard-template.md. Decide: iterate title/thumbnail, or proceed.

## Kill criteria (set before launch)
- < 200 listing visits after all 7 days executed -> distribution problem: one more HN/Reddit cycle with new angle, then stop.
- > 150 visits and 0 sales -> offer/pricing problem: add video + drop to $29 for 2 weeks; if still 0, kill.
- First 5 sales -> validate: email buyers, ask what almost stopped them.
